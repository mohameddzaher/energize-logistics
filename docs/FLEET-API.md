# واجهة الأسطول المباشر — دليل الاستعمال

واجهةُ **قراءةٍ فقط** تُعطيك حالة أسطول الشاحنات لحظةً بلحظة: الموقع والسرعة
وحرارة المحرّك، وحرارة كل فردةِ إطارٍ وضغطها بموضعها، والتنبيهات المفتوحة.

مُعدّةٌ للأتمتة: تسألها كل دقيقة، وتبني عليها شرطك — «لو ضغط أيّ فردة نزل عن
كذا» أو «لو حرارة إطار تجاوزت ٩٠ درجة» — فتُرسل رسالةً أو تفتح تذكرة.

---

## العنوان والمفتاح

```
https://api.energize-logistics.com/api/fleet-api
```

كلّ طلبٍ يحمل المفتاح في ترويسة `x-api-key`:

```bash
curl -H "x-api-key: <المفتاح>" \
  https://api.energize-logistics.com/api/fleet-api/vehicles
```

> المفتاح يصلك من مالك النظام. لا تضعه في شيفرةٍ تُرفَع إلى مستودع؛ ضعه في
> متغيّر بيئة. وهو يقبل أيضًا `?key=` في نصّ الاستعلام لأدواتٍ لا ترسل
> ترويسات — لكنّ نصّ الاستعلام يُسجَّل في سجلّات الوصول، فالترويسة أسلم.

---

## من أين تأتي البيانات

نظامُنا يسحب كلّ الوحدات من مزوّد التتبّع **كل عشرين ثانية**، يفكّ قراءات
الحسّاسات، ويحفظ لقطةً لكلّ مركبة. أنت تقرأ من قاعدتنا لا من المزوّد — فالردّ
أسرع، ولا يستهلك حصّتنا مهما تكرّر نداؤك، ويحمل معه ما نعرفه نحن عن الإطارات
المسجَّلة وهو ما لا يعرفه المزوّد.

**ولذلك** كلّ ردٍّ يحمل `dataAgeSeconds`: عمرُ القراءة بالثواني. قراءةٌ عمرها
ساعة ليست حالةً حاليّة. **تحقّق منه قبل أن تبني قرارًا** — شاحنةٌ في منطقةٍ بلا
تغطية تُرجع آخر ما وصل منها، لا ما هي عليه الآن.

## النقاط

### `GET /health`
تحقّقٌ من المفتاح وحياة النبض. نادِها أوّلًا.

```json
{ "ok": true, "pollHealthy": true, "newestReadingAgeSeconds": 14 }
```

`pollHealthy: false` يعني أن السحب من المزوّد متوقّف — **لا تُنبِّه بناءً على
بياناتٍ في هذه الحالة**، فغيابُ تنبيهٍ حينها لا يعني أن كل شيء سليم.

---

### `GET /vehicles`
كلّ المركبات بلقطتها الأخيرة. `?plate=أ ب ج 1234` يقصرها على واحدة.

```json
{
  "generatedAt": "2026-08-26T10:20:00.000Z",
  "count": 57,
  "vehicles": [{
    "plate": "أ ب ج 1234",
    "unitId": 401234,
    "online": true,
    "lastMessageAt": "2026-08-26T10:19:46.000Z",
    "dataAgeSeconds": 14,
    "driver": "اسم السائق",
    "position": { "lat": 21.48, "lng": 39.19, "speed": 82, "course": 140 },
    "engine": { "ignition": true, "moving": true, "speedKmh": 82, "rpm": 1450, "coolantC": 88, "engineHours": 12043 },
    "odometerKm": 418302,
    "fuelPct": 61,
    "weightKg": 32400,
    "power": { "mainV": 27.4, "backupV": 4.1, "gsm": 4 },
    "tyres": {
      "count": 12, "faults": 1,
      "maxTempC": 74, "minTempC": 48,
      "maxPressurePsi": 118, "minPressurePsi": 96,
      "readings": [
        { "axle": 1, "position": 1, "tempC": 52, "pressurePsi": 116, "fault": false },
        { "axle": 3, "position": 2, "tempC": 74, "pressurePsi": 96,  "fault": true }
      ],
      "registered": { "mounted": 12, "spare": 2, "withSensor": 7 }
    }
  }]
}
```

**`readings`** هو ما تبني عليه شرطك: كلّ فردةٍ بمحورها وموضعها.
**`registered`** ما نعرفه نحن: كم فردةً مركَّبة فعلًا وكم منها عليها حسّاس —
فتعرف أن `count: 7` ليس عطلًا بل أن خمسًا بلا حسّاس بعد.

`fault: true` تعني أن الحسّاس نفسه معطوب أو لا يبثّ. **لا تقرأ قيمته حينها**:
حرارةٌ تُقرأ صفرًا من حسّاسٍ ميّت ليست حرارةً منخفضة.

مركبةٌ واحدة بنفس الشكل.

### `GET /alerts`
التنبيهات المفتوحة كما يراها نظامنا، بعتباتٍ يضبطها فريقنا من الشاشة.

```json
{ "count": 3, "alerts": [
  { "plate": "أ ب ج 1234", "type": "tire_temp_high", "severity": "critical",
    "message": "حرارة إطار مرتفعة", "value": 94,
    "raisedAt": "2026-08-26T09:58:00.000Z", "ageSeconds": 1320 }
]}
```

مُرشِّحات: `?plate=` و`?type=` (يقبل أكثر من نوعٍ مفصولةً بفواصل).

> **متى تستعمل هذه بدل حساب شرطك؟** حين تريد أن يصل تغييرُ العتبة من شاشتنا
> إلى أتمتتك بلا تعديل شيفرتك. وإن كان لك شرطٌ خاصّ لا يعرفه نظامنا، احسبه من
> `readings`.

## حدودٌ يلزم أن تعرفها

| | |
|---|---|
| **قراءةٌ فقط** | لا كتابة بحال. الأتمتة تراقب وتُنبِّه؛ ومَن يغيّر في النظام يدخل كإنسانٍ بصلاحياته. |
| **ذاكرةٌ عشر ثوانٍ** | نداءان في ثانيةٍ يعطيان الردّ نفسه. النبض كلّ عشرين ثانية، فالنداء أكثر من مرّةٍ كلّ عشرين ثانية لا يفيد. |
| **الوتيرة الموصى بها** | مرّة كلّ دقيقة. |
| **التنبيهات** | حتى ٥٠٠ في الردّ الواحد. |
| **الترميز** | UTF-8. اللوحات عربيّة — رمِّزها في نصّ الاستعلام (`encodeURIComponent`). |
| **التواريخ** | ISO 8601 بتوقيت UTC. |

## مثالٌ عامل

```javascript
const KEY = process.env.FLEET_API_KEY;
const BASE = 'https://api.energize-logistics.com/api/fleet-api';

async function check() {
  const h = await (await fetch(`${BASE}/health`, { headers: { 'x-api-key': KEY } })).json();
  // نبضٌ متوقّف يعني أن ما سنقرؤه بائت — والصمت حينها ليس طمأنينة.
  if (!h.pollHealthy) return console.warn('السحب متوقّف — لا تُبنى قرارات الآن');

  const { vehicles } = await (await fetch(`${BASE}/vehicles`, { headers: { 'x-api-key': KEY } })).json();

  for (const v of vehicles) {
    if (v.dataAgeSeconds > 600) continue;            // قراءةٌ أقدم من عشر دقائق: تُتجاوز
    for (const t of v.tyres.readings) {
      if (t.fault) continue;                          // حسّاسٌ معطوب: قيمتُه لا تُقرأ
      if (t.tempC != null && t.tempC >= 90)
        notify(`${v.plate}: حرارة الإطار (محور ${t.axle} موضع ${t.position}) ${t.tempC}°`);
      if (t.pressurePsi != null && t.pressurePsi < 90)
        notify(`${v.plate}: ضغط منخفض (محور ${t.axle} موضع ${t.position}) ${t.pressurePsi} psi`);
    }
  }
}

setInterval(check, 60_000);
```

## أخطاء

| الرمز | المعنى |
|---|---|
| `401` | مفتاحٌ ناقص أو خاطئ |
| `404` | لوحةٌ غير موجودة |
| `503` | المفتاح غير مضبوطٍ على الخادم — راجع مالك النظام |
| `500` | عطلٌ عندنا — أعد المحاولة بتراجعٍ تصاعديّ |

للاستفسار: مالك النظام.
