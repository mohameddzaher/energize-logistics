# Energize Logistics — working rules

## Code comments
- Every comment in the code (`//`, `/* */`, JSDoc, Dart `///`, shell `#`) is **English**, short and technical.
- A comment explains *why*, in a line or two. No dates, no narration ("the owner said…", "this happened on…"), no decorative `── … ──` banners. If the code already says it, write no comment.
- When you edit a file, rewrite its Arabic comments in concise English (at least the parts you touch).
- User-facing strings (labels, messages) stay Arabic/bilingual. This rule is about comments only.

## Git
- Commit messages and PR text are English.
